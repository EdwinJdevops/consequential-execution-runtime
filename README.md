# Consequential Execution Runtime (CER)

CER is an execution-safety runtime research project for consequential autonomous operations across heterogeneous external systems.

The current milestone is deliberately narrow: formal execution semantics, explicit ambiguous-outcome handling, approval/state binding, recovery contracts, and an adapter boundary. It does not yet claim a bypass-resistant production enforcement boundary.

M0 reconstruction is in progress. The repository must pass formatting, Clippy, and workspace tests before M0 is considered verified.
